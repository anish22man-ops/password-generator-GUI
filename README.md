### Password Generator GUI ###

A simple desktop Password Generator application developed using Python and Tkinter. The application allows users to generate customizable passwords based on length and selected character types.

## Features

* Generate random passwords
* Customize password length
* Include uppercase letters
* Include lowercase letters
* Include numbers
* Include special characters
* Copy generated passwords to the clipboard
* Clear generated passwords
* Input validation
* Simple graphical user interface

## Technologies Used

* Python
* Tkinter
* Random module
* String module

### How It Works ###
The application allows the user to select the desired password length and character types. Based on these selections, the program creates a random password and displays it in the GUI.

The generated password can then be copied directly to the clipboard.

## How to Run ###

1. Clone the repository
git clone https://github.com/anish22man-ops/password-generator-gui.git


2. Open the project
Open the project in PyCharm, VS Code, or another Python IDE.


3. Run the Python file
python password_generator.py


Tkinter is included with most standard Python installations, so no additional external packages are required.
